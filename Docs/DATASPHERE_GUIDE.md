# 🪐 Руководство: Запуск обучения Unity ML-Agents в Yandex DataSphere

Использование **Yandex DataSphere** вместо классических виртуальных машин (Compute Cloud) имеет огромные преимущества для учебного кемпа. Это избавляет студентов от необходимости настраивать SSH-ключи, использовать командную строку Windows для копирования файлов и пробрасывать порты для TensorBoard.

---

## 💎 Почему DataSphere — это круто для студентов:
1.  **Загрузка файлов перетаскиванием**: Архив симулятора `Build_Linux.zip` можно просто перетащить мышкой в веб-интерфейс.
2.  **Скачивание модели в один клик**: Готовый файл `.onnx` скачивается через контекстное меню (правой кнопкой мыши ➔ Download).
3.  **Встроенный TensorBoard**: Графики обучения отображаются прямо внутри веб-страницы блокнота.
4.  **Автовыключение при простое**: Как только обучение завершится, облачная машина автоматически отключится, что полностью исключает перерасход бюджета из-за забытых на ночь серверов.

---

## 🛠 Пошаговый алгоритм запуска

### Шаг 1: Создание проекта в DataSphere
1.  Перейдите в консоль Yandex Cloud и откройте сервис **DataSphere**.
2.  Нажмите **Создать проект** (Create project), укажите имя и выберите платежный аккаунт.
3.  Откройте созданный проект (нажмите **Открыть в JupyterLab**).

### Шаг 2: Загрузка файлов
В левой панели JupyterLab находится файловый менеджер.
1.  Перетащите туда мышкой файл конфигурации **`config.yaml`**.
2.  Перетащите туда же архив вашего Linux-симулятора **`Build_Linux.zip`**.

### Шаг 3: Создание ноутбука (Notebook)
1.  В главном окне (Launcher) выберите **Python 3 (Local)** в разделе *Notebook*. Создастся файл с расширением `.ipynb`.
2.  В верхнем правом углу ноутбука найдите выпадающий список выбора вычислительных ресурсов (по умолчанию там стоит `c1.4`).
3.  Выберите конфигурацию **`c1.8`** (8 ядер CPU, 64 ГБ RAM) — это оптимальный выбор по цене/скорости.

---

### Шаг 4: Подготовка окружения (Выполнение ячеек)

Создайте в ноутбуке ячейки с кодом ниже и запустите их по очереди (сочетанием клавиш `Shift + Enter`).

#### Ячейка 1: Распаковка архива симулятора средствами Python (без sudo/unzip)
```python
import zipfile
import os

# Распаковываем симулятор
with zipfile.ZipFile('Build_Linux.zip', 'r') as zip_ref:
    zip_ref.extractall('Build_Linux')

# Даем права на выполнение исполняемому файлу симулятора (замените ROStest.x86_64 на свой файл)
os.chmod('Build_Linux/Build_Linux/ROStest.x86_64', 0o755)
print("Распаковка завершена, права выданы!")
```

#### Ячейка 2: Установка зависимостей (ML-Agents и совместимый setuptools)
```python
# Символ "!" в начале строки позволяет выполнять bash-команды в ячейках
!pip install torch~=2.2.1 --index-url https://download.pytorch.org/whl/cpu
!pip install "setuptools<70"
!pip install mlagents==1.1.0
```

---

### Шаг 5: Встраивание TensorBoard в ноутбук

Создайте ячейку для запуска TensorBoard. Графики будут рисоваться прямо внутри вашего блокнота!

#### Ячейка 3: Запуск TensorBoard
```python
%load_ext tensorboard
%tensorboard --logdir results
```

---

### Шаг 6: Запуск процесса обучения

Запустите ячейку с командой обучения.
*   *Обратите внимание*: Для конфигурации `c1.8` (8 ядер) параметр `--num-envs` следует выставить равным **8**.

#### Ячейка 4: Обучение
```python
!mlagents-learn config.yaml --run-id=datasphere_test --env=Build_Linux/Build_Linux/ROStest.x86_64 --num-envs=8 --no-graphics --env-args -logFile /dev/null
```

> [!IMPORTANT]
> **Как работает фоновое обучение**:
> Пока ячейка с обучением выполняется, виртуальная машина считается активной. Студенты могут спокойно **закрыть вкладку браузера и выключить компьютер**. Процесс обучения на сервере Yandex Cloud не прервется.
> Когда обучение завершится (или дойдет до лимита шагов), ячейка завершит выполнение, и DataSphere автоматически выключит виртуальную машину, чтобы не тратить деньги.

---

### Шаг 7: Получение результатов
1.  Вернитесь в DataSphere через некоторое время и откройте проект.
2.  В левой панели файлового менеджера обновите дерево каталогов.
3.  Перейдите в папку `results/datasphere_test/`.
4.  Нажмите правой кнопкой мыши на файл **`GFSX_Brain.onnx`** и выберите **Download**. Модель скачается на ваш локальный компьютер.
