# 🤖 GFS-X Sim-to-Real RL Agent (v27)

Этот проект посвящен разработке системы управления гусеничным роботом **XiaoR Geek GFS-X** (на базе Raspberry Pi 4B) для **автономного поиска и захвата мяча клешнёй**. 

Обучение агента происходит в симуляторе Unity с использованием библиотеки **ML-Agents (PPO + LSTM)**, после чего обученная политика (`.onnx`) переносится на физического робота для управления в реальном времени через ROS-мост или автономный инференс на борту.

---

## 🌟 Ключевые особенности проекта
* **Sim-to-Real адаптация:** Решены проблемы разрыва в физике и задержках (Reality Gap & Latency Gap) с помощью EMA-фильтрации команд руления, калибровки мертвых зон двигателей (Deadzone Mapping) и искусственного джиттера/задержек в симуляции.
* **LSTM память:** Использование рекуррентных слоев (длина последовательности 64, размер памяти 256) позволяет роботу ориентироваться при кратковременной потере мяча из виду.
* **Обход слепых зон (Blind Crawl):** Специальный алгоритм наград стимулирует робота продолжать движение по направлению к мячу в «слепой зоне» перед самой клешнёй, где камера его уже не видит.
* **Domain Randomization:** Рандомизация массы робота, трения, скорости двигателей, размеров и положения мяча при обучении повышает устойчивость модели к физическим неточностям реального мира.

## 🛠 Стек технологий
* **Unity 3D / C#** — создание среды симуляции, физического робота и начисление наград.
* **Unity ML-Agents** (PPO + LSTM) — фреймворк и алгоритмы обучения с подкреплением.
* **Python 3 / ONNX Runtime** — бортовой инференс нейросети на Raspberry Pi.
* **ROS Noetic (ROS 1)** — обмен сообщениями между сенсорами, моторами и управляющим узлом.
* **YOLO (v8, v11, v26)** — детектирование мяча на кадрах с камеры в реальном времени (30-40 FPS).

## 🧠 Математика агента (v26 / v27)

### 1. Пространство наблюдений (Observation Space)
Вектор наблюдений состоит из **15 значений**, которые накапливаются по **4 кадра (stacked)**, формируя **60 входов** для LSTM-сети:
* `[0]` Показания УЗ дальномера (нормализованные 0–1).
* `[1-2]` Левый и правый ИК-датчики препятствий на бампере (0 или 1).
* `[3]` ИК-датчик клешни (1 — объект внутри клешни, 0 — пусто).
* `[4]` Горизонтальный угол до мяча относительно камеры (от -1 до 1).
* `[5]` Расстояние до мяча (нормализованное, 1 — не виден).
* `[6]` Направление последнего обнаружения мяча (-1 — влево, 1 — вправо).
* `[7]` Флаг видимости мяча (0 или 1).
* `[8]` Поворот камеры по оси Y (Yaw, от -1 до 1).
* `[9]` Наличие мяча в клешне (0 или 1).
* `[10-11]` Смещение робота по осям X и Z (Ego одометрия).
* `[12]` Направление движения (Heading).
* `[13]` Текущая скорость (Speed).
* `[14]` Время, прошедшее с момента потери видимости мяча.

### 2. Пространство действий (Action Space)
* **Continuous Actions (3):**
  * `Gas` — движение вперед/назад (диапазон `[-1, 1]`).
  * `Steering` — поворот влево/вправо (диапазон `[-1, 1]`).
  * `Camera Yaw` — поворот сервопривода камеры (диапазон `[-1, 1]`).
* **Discrete Actions (1):**
  * `Gripper` — команда клешне: `0` — ничего не делать (NOOP), `1` — закрыть (CLOSE), `2` — открыть (OPEN).

### 3. Функция наград (Dense Reward System)
Самым успешным обучением является запуск **`YAcampv2`** (50 млн шагов). В нем используется комбинированная система наград:
1. **Приближение к мячу:** Динамическая награда `delta_distance * (2.0 + 4.0 * (1 - dist))` (стимулирует быстрее ехать к цели).
2. **Захват цели (Terminal Grab):** `+5.0` при удержании мяча в клешне более 50 физических шагов.
3. **Удержание цели (Hold Reward):** `+0.02` за каждый шаг удержания мяча.
4. **Центрирование на мяч (Alignment Bonus):** `+0.005` при небольшом расстоянии и точном наведении по центру камеры.
5. **Безопасность движения:** Штрафы за опасное сближение со стенами по датчикам, резкие смены команд ШИМ (Action Rate Penalty `-0.05`) и беспричинное движение назад.

## 🚀 Быстрый старт

### Обучение ML-Agents (на ПК или в облаке Yandex Cloud)
Для запуска обучения в симуляции с 16 параллеющими средами без вывода графики (высокая скорость сбора данных):
```bash
mlagents-learn config.yaml --env=Buildv31/ROS_test --run-id=YAcampv2 --num-envs=16 --no-graphics --env-args -logFile nul
```

### Автономный запуск ONNX-модели на ПК/роботе
Скрипт `onnx_brain.py` (в папке `Analyze/`) позволяет запустить инференс обученной политики напрямую через ONNX Runtime без использования запущенного редактора Unity. Он подписывается на ROS-топики датчиков и YOLO, рассчитывает действия и публикует управляющие команды в `/cmd_vel` и `/cmd_gripper`:
```bash
python3 onnx_brain.py --model UnityProject/Assets/GFSX_Brain.onnx
```

## 🎓 Ценность проекта для портфолио
Проект демонстрирует глубокое понимание концепций робототехники и ИИ:
1. **Создание цифровых двойников** в Unity с точным переносом физических параметров (масса, инерция, силы трения) и кинематики гусеничной платформы.
2. **Обучение с подкреплением (RL)** сложных многофакторных агентов с непрерывным и дискретным управлением.
3. **Преодоление Sim-to-Real Reality Gap** за счет калибровки задержек сенсоров/актуаторов, EMA-фильтров и рандомизации окружения.
4. **Интеграция ROS-архитектуры** с нейросетевыми методами управления и детекцией компьютерного зрения (YOLO).
